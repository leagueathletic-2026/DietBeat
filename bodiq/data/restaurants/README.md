# ملفات المطاعم

ملف واحد لكل مطعم، باسم المطعم بالإنجليزي: `buffalo-burger.csv`, `kfc-egypt.csv` ...
انسخ `_TEMPLATE.csv` واملأه. الحقول الاختيارية ممكن تتساب فاضية (لا تكتب 0 لو مش عارف).

## القواعد
- `data_status`: `verified` فقط لو القيم من جدول غذائي رسمي للمطعم (موقع / PDF / تطبيق / عبوة). غير كده `estimated`.
- `source`: اكتب مصدر كل صنف (رابط أو اسم الملف). بدون مصدر = يتسجل `estimated`.
- `serving_g`: وزن الوجبة بالجرام لو معروف. لو مش معروف سيبه فاضي وهنقدّره من المكونات.
- الأرقام للوجبة كلها (مش لكل 100 جم). استخدم نقطة عشرية `.`.
- صور الأصناف: حطها في `images/<restaurant>/` وكتب اسم الملف في `image_file`.
- الصيغ المقبولة: CSV، Excel، PDF المنيو، أو صور المنيو (هقرأها وأحوّلها لـ CSV وأعرضلك للمراجعة).
